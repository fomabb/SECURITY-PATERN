# Техническое задание для Frontend: Реализация Чатов и Групп

## 1. Введение

Цель этого задания — реализовать клиентскую часть полнофункционального чата. Система включает в себя:

- **Управление Группами:** Создание, удаление, просмотр, вступление и выход из групповых чатов.
- **Приватные Чаты:** Создание чатов "один на один" между пользователями.
- **Обмен Сообщениями:** Отправка и получение сообщений в реальном времени в любом типе чата.

Взаимодействие с бэкендом строится на двух протоколах: **REST API** для управления и **WebSocket (STOMP)** для real-time
коммуникаций.

## 2. Аутентификация

Все эндпоинты защищены с помощью **JWT**. Клиент должен получить токен после логина и передавать его при каждом
взаимодействии.

- **Для REST-запросов**: Токен передается в заголовке `Authorization`.
  ```
  Authorization: Bearer <ваш_jwt_токен>
  ```
- **Для WebSocket-подключения**: Токен передается в заголовках при установке STOMP-соединения.
  ```javascript
  const headers = {
      'Authorization': 'Bearer <ваш_jwt_токен>'
  };
  stompClient.connect(headers, onConnected, onError);
  ```

## 3. Управление Группами (REST API)

Все эндпоинты находятся по базовому пути: `/api/v1/groups`.

#### 3.1. Получить список всех групп

- **Метод и Путь**: `GET /api/v1/groups`
- **Описание**: Возвращает страницу со списком всех публичных групп с пагинацией.
- **Query-параметры**: `page`, `size`, `sort` (стандартные для Spring `Pageable`).
- **Успешный ответ (200 OK)**: `Page<GroupChatListDto>` (см. Модели данных).

#### 3.2. Получить детальную информацию о группе

- **Метод и Путь**: `GET /api/v1/groups/{groupId}`
- **Описание**: Возвращает полную информацию о конкретной группе.
- **Успешный ответ (200 OK)**: `GroupChatDetailsDto`.
- **Ошибки**: `404 Not Found`, если группа не найдена.

#### 3.3. Создать новую группу

- **Метод и Путь**: `POST /api/v1/groups`
- **Описание**: Создает новую группу. Текущий пользователь автоматически становится ее владельцем.
- **Тело запроса**: `GroupChatCreateRequest`.
  ```json
  {
    "title": "Новая группа 'Котики'",
    "description": "Обсуждаем все о котиках",
    "coverUrl": "https://example.com/cover.jpg",
    "type": "OPEN",
    "isClubGroup": false,
    "clubId": null
  }
  ```
- **Успешный ответ (201 Created)**: `GroupChatDetailsDto` созданной группы.
- **Ошибки**: `400 Bad Request` при ошибке валидации.

#### 3.4. Удалить группу

- **Метод и Путь**: `DELETE /api/v1/groups/{groupId}`
- **Описание**: Удаляет группу. Доступно только для владельца.
- **Успешный ответ (204 No Content)**.
- **Ошибки**: `403 Forbidden` (не владелец), `404 Not Found`.

#### 3.5. Вступить в группу

- **Метод и Путь**: `POST /api/v1/groups/{groupId}/join`
- **Описание**: Позволяет текущему пользователю вступить в группу.
- **Успешный ответ (200 OK)**.
- **Ошибки**: `403 Forbidden` (для приватных групп), `404 Not Found`.

#### 3.6. Покинуть группу

- **Метод и Путь**: `DELETE /api/v1/groups/{groupId}/leave`
- **Описание**: Позволяет текущему пользователю выйти из группы.
- **Успешный ответ (204 No Content)**.
- **Ошибки**: `400 Bad Request` (владелец не может выйти), `404 Not Found`.

## 4. Обмен Сообщениями (REST & WebSocket)

#### 4.1. Найти или создать приватный чат (REST)

- **Метод и Путь**: `POST /api/v1/chats/private/{recipientId}`
- **Описание**: Находит или создает приватный чат с указанным пользователем и возвращает ID комнаты.
- **Успешный ответ (200 OK)**:
  ```json
  {
    "roomId": "a1b2c3d4-e5f6-1234-abcd-567890abcdef"
  }
  ```

#### 4.2. Получить историю сообщений (REST)

- **Метод и Путь**: `GET /api/v1/chats/{roomId}/messages`
- **Описание**: Возвращает страницу с историей сообщений для любого чата (приватного или группового).
- **Query-параметры**: `page`, `size`, `sort`.
- **Успешный ответ (200 OK)**: `Page<ChatMessageDto>`.
- **Ошибки**: `403 Forbidden`, если пользователь не является участником чата.

#### 4.3. WebSocket API

- **Эндпоинт подключения**: `/ws` (с поддержкой SockJS).
- **Заголовки подключения**: `{ 'Authorization': 'Bearer <токен>' }`.

##### Подписки (Subscribe)

1. **Получение новых сообщений:**
    - **Топик**: `/topic/room/{roomId}`
    - **Тело ответа**: `ChatMessageDto`

2. **Получение событий "печатает":**
    - **Топик**: `/topic/room/{roomId}/typing`
    - **Тело ответа**: `{"userId": "...", "userName": "..."}`

##### Отправка (Send)

1. **Отправка нового сообщения:**
    - **Адрес**: `/app/chat/{roomId}/sendMessage`
    - **Тело запроса**: `MessageSendRequest`
      ```json
      { "content": "Привет! Как дела?" }
      ```

2. **Отправка события "печатает":**
    - **Адрес**: `/app/chat/{roomId}/typing`
    - **Тело запроса**: Пустое.

## 5. Модели Данных (DTO)

#### `GroupChatCreateRequest` (клиент -> сервер)

*Объект для создания группы.*

```json
{
  "title": "string",
  "description": "string",
  "coverUrl": "string",
  "type": "OPEN"
  |
  "BY_REQUEST"
  |
  "PRIVATE",
  "isClubGroup": "boolean",
  "clubId": "uuid"
}
```

#### `GroupChatListDto` (сервер -> клиент)

*Краткая информация о группе для списков.*

```json
{
  "id": "uuid",
  "title": "string",
  "coverUrl": "string",
  "memberCount": "integer"
}
```

#### `GroupChatDetailsDto` (сервер -> клиент)

*Полная информация о группе. Содержит `chatRoomId` для подписки на WebSocket.*

```json
{
  "id": "uuid",
  "chatRoomId": "uuid",
  "title": "string",
  "description": "string",
  "coverUrl": "string",
  "type": "string",
  "createdByUserId": "uuid",
  "createdAt": "datetime"
}
```

#### `MessageSendRequest` (клиент -> сервер)

*Объект для отправки сообщения.*

```json
{
  "content": "string"
}
```

#### `ChatMessageDto` (сервер -> клиент)

*Основной объект сообщения.*

```json
{
  "id": "uuid",
  "roomId": "uuid",
  "content": "string",
  "senderId": "uuid",
  "senderName": "string",
  "senderAvatarUrl": "string",
  "createdAt": "datetime"
}
```

## 6. Основные Сценарии (User Flows)

#### Сценарий А: Пользователь создает новую группу и пишет в нее.

1.  Отправить `POST /api/v1/groups` с данными новой группы.
2.  Из ответа (`GroupChatDetailsDto`) извлечь `chatRoomId`.
3.  Подключиться к WebSocket и подписаться на топик `/topic/room/{chatRoomId}`.
4.  Отправить `GET /api/v1/chats/{chatRoomId}/messages` для загрузки истории (будет пустой).
5.  Отправить сообщение через WebSocket на `/app/chat/{chatRoomId}/sendMessage`.

#### Сценарий Б: Пользователь хочет написать личное сообщение другому пользователю.
1.  Отправить `POST /api/v1/chats/private/{recipientId}`.
2.  Из ответа извлечь `roomId`.
3.  Далее следовать шагам 3-5 из Сценария А, используя полученный `roomId`.
